# 一键日课任务设计

> 2026-09-12 更新。本文记录当前一键日课的已实现流水线设计与测试边界。该功能仍处于测试阶段，运行时必须有人看管。

## 一、功能目标

「一键日课」是独立的流水线任务，入口为 `DailyTask`。用户可按需启用日课项目，任务按固定顺序依次执行；未启用的项目会直接跳过。

当前固定顺序：

```text
登录奖励
  → 暖心礼包
  → 合成
  → 锻刀
  → 演练
  → 领取奖励
```

检非违使流程仍保留在 `DailyTask.json` 中，但暂未注册为日课选项，因此当前不会执行。

## 二、任务选项

所有日课项目默认关闭。启用的项目由 `assets/interface.json` 的 `pipeline_override` 打开对应枢纽。

| 选项 | 默认值 | 说明 |
|---|---:|---|
| 同步后勤 | 关闭 | 使用「本丸后勤」任务中的设置，在日课开始前处理一次远征派遣、修刀与内番，再执行各日课项目。 |
| 登录奖励 | 关闭 | 领取每日登录签到奖励。 |
| 暖心礼包 | 关闭 | 进入万屋领取免费礼包。 |
| 合成 | 关闭 | 固定选择合成页面的第一把可合成刀剑作为强化对象，再从刀解/合成许可名单中选择一把未上锁刀剑作为材料。 |
| 锻刀 | 关闭 | 收取已完成锻刀后，按所选锻刀公式最多锻造三把，不使用加速符。 |
| 锻刀 → 锻刀公式 | ALL 50 | 可选限锻公式、限锻优先、ALL 50；选择限锻公式时未检测到限锻活动会跳过锻刀。 |
| 锻刀 → 刀解 | 关闭 | 刀位不足时允许进入刀解流程；关闭时直接跳过锻刀。 |
| 演练 | 关闭 | 最多处理五个对手位置，累计胜利三次或完成五个位置即结束。 |
| 演练 → 选择部队 | 部队一 | 选择部队一至部队五；每次选队均连续点击两次，间隔 500ms。 |
| 演练 → 选择阵形 | 不启用 | 可选鱼鳞阵、横队阵、雁行阵、鹤翼阵、方阵、逆行阵。 |
| 演练 → 避战强敌 | 关闭 | 开启时分析对手配置，危险度达到六时离开，不进入战斗。 |
| 领取奖励 | 关闭 | 仅一键领取日课奖励。 |

## 三、总流程与枢纽

```text
DailyTask
  → DT_DetectWhereAmI
  → DT_PrepareHub
  → DT_LoginRewardGate
  → DT_WarmGiftGate
  → DT_MixGate
  → DT_ForgeGate
  → DT_DrillGate
  → DT_KebiGate（当前直接跳过）
  → DT_RewardGate
  → DT_Finish
```

每个 Gate 负责两件事：进入已启用项目的主枢纽，以及在项目未启用时前往下一个 Gate。各项目结束后先通过专用返回本丸枢纽确认回到本丸，再继续后续项目；领取奖励完成后直接结束日课。

### 3.1 起始画面识别

`DT_DetectWhereAmI` 用于将起始画面收敛到本丸：

- 处理经验结算、刀剑掉落、公告、修行书信与内番报告。
- 处理游戏图标、登录页、游戏更新、游戏内更新与连接中断。
- 退出部队记录页面。
- 通过亮度检测与本丸模板确认位于本丸。

候选列表以 `DT_CheckHomeBrightness` 打头，本丸确认链为 `DT_CheckHomeBrightness → DT_IsHome → DT_CheckHomeBrightness2 → DT_IsHome2 → DT_PrepareHub`；目录按钮与菜单目录识别（`DT_DetectClickMenu`、`DT_DetectMenuDirectory`）排在列表末尾作为兜底，避免在本丸启动时先点开目录而跳过本丸确认。识别超时（120 秒）按 `DT_RestartGame` 重启游戏后重新识别。

### 3.2 子任务通用恢复

登录奖励、暖心礼包、合成、锻刀、演练、检非违使、领取奖励的主枢纽都通过 `[JumpBack]` 引用以下处理流程：

| 处理流程 | 识别方式 | 处理后行为 |
|---|---|---|
| `DT_HandleExperience` | OCR「经验」 | 点击左上角返回区域。 |
| `DT_HandleSwordDrop` | 刀剑掉落颜色匹配 | 点击结算继续区域。 |
| `DT_HandleTrainingLetter` | 修行书信模板 | 点击关闭。 |
| `DT_HandleInternalReport` | 内番报告模板 | 点击关闭。 |
| `DT_HandleGameIcon` | 游戏图标模板 | 点击重新进入游戏。 |
| `DT_HandleLoginButton` | 登录模板 | 点击登录。 |
| `DT_HandleGameUpdatePopup` | 游戏更新模板 | 点击关闭。 |
| `DT_HandleInGameUpdatePopup` | OCR「更新」 | 点击更新弹窗确认区域。 |
| `DT_HandleConnectionInterrupted` | OCR「连接中断」 | 点击重连确认区域。 |

这些处理流程完成后会回流到当前子任务主枢纽，不会返回日课总入口。各子任务的 `FallbackWait` 均为 `DoNothing`，只承担重新识别作用，不再执行点击，避免未知画面误触。

## 四、项目流程

### 4.1 登录奖励

1. 从本丸菜单进入公告。
2. 关闭公告后识别「签到」。
3. 若每日奖励可领取则领取，并循环关闭领取弹窗。
4. 若已领取则输出「日课 登录奖励 已被领取」。
5. 完成后输出领取结果并返回本丸。

### 4.2 暖心礼包

1. 通过右上角目录进入万屋。
2. 以 OCR「所持道具」确认位于礼包页面。
3. 依次检查四个礼包位置的「领取」按钮。
4. 领取后关闭购买详情与领取弹窗；无可领取礼包时输出已领取日志。
5. 输出「日课 暖心礼包 领取完成」后返回本丸。

### 4.3 合成

1. 从本丸进入强化，再切换至刀剑合成页面。
2. 固定选择页面中第一把可合成刀剑作为强化对象。
3. 在素材列表中按刀解/合成许可名单寻找未上锁刀剑；当前页无可用素材时连续上滑，最多十次。
4. 找到素材后点击选择、确认素材，再连续点击合成确认。
5. 未找到可用素材时输出「日课 合成 未找到可用素材」；完成时输出「日课 合成 完成」。
6. 返回本丸。

### 4.4 锻刀与刀解

1. 进入锻刀状况页面，`ForgeCapacityCheckAction` 读取所持刀剑上限及可收取数量。
2. 先进入收取枢纽，依次点击「完成」与「十连完成」；跳过掉落动画后记录刀剑掉落名称。
3. 收取结束后依次寻找空闲锻冶所，最多锻造三次。
4. 每次进入资源投入页面后先按所选公式处理。`DT_ForgeDetectResourceInput` 的 `next` 固定列出三个公式入口，档位只覆盖 `enabled` 来选择生效入口（三个入口都是无识别节点，恒命中，因此只能靠 `enabled` 切换）：
   - `DT_ForgeFormulaAll50`（默认启用）：直接接 ALL 50 链路。
   - `DT_ForgeFormulaLimited`（默认关闭）：`next` 为限锻判定与 `DT_ForgeSkipCurrentRun`，判定不中即跳过锻刀。
   - `DT_ForgeFormulaLimitedFirst`（默认关闭）：`next` 为限锻判定与 `DT_ForgeFormulaAll50`，判定不中即回落 ALL 50。
   - 限锻优先档必须让 `DT_ForgeFormulaAll50` 保持启用：它既是回落目标，也是 `DT_ForgeDetectResourceInput` 的第三个候选，误把它一并关掉会让判定不中时无候选可走，节点只能等 `timeout` 到期报 `bad next`，整条日课任务失败。
5. 限锻判定与勾选全部用 `next` 分流，`on_error` 只承担失败出口：
   - `DT_ForgeLimitedDetect` 在 `[971,144,5,2]` 匹配限锻指示色 `[2,103,115]`（`count: 10`，全部像素命中即当期有限锻；该 ROI 是「限定鍛刀公式」条幅底色）。识别不中的当轮即落入下一个候选，也就是跳过出口或 ALL 50 入口。
   - 判定命中后进入 `DT_ForgeLimitedChecked`，在勾选框区域 `[939,139,30,29]` 匹配红色对勾（RGB 范围 `150~210 / 0~80 / 0~80`，`count: 20`）。当轮命中直接接 `DT_ForgeClickStart`；未命中即接 `DT_ForgeLimitedClick` 点击该区域勾选。
   - 点击后回到 `DT_ForgeLimitedDetect` 重新判定，勾选生效即进入锻刀；`DT_ForgeLimitedChecked` 与 `DT_ForgeLimitedClick` 识别不到后续节点时走 `on_error → DT_ForgeSkipCurrentRun`，记录本次锻刀跳过并返回本丸。
6. 公式就绪后点击锻刀，三次完成时输出「日课 锻刀 已完成 3 次锻刀」；中途无空闲锻冶所时输出实际完成次数。

启用「锻刀 → 刀解」时，刀位不足会进入刀解流程：

- 取消「显示保护中的刀剑男士」。
- 使用 `ForgeDisassembleSelectAction` 按刀解/合成许可名单选择刀剑；每页处理后读取已选数量，未达到所需数量时连续下滑。
- 滑到底且可选刀剑不足时输出「日课 锻刀 刀位不足 可刀解刀剑不足」，跳过后续锻刀。
- 单次刀解最多选择 30 把；达到缺口或选择满 30 把后确认刀解，并返回锻刀状况重新计算。

锻刀流程完成或跳过后返回本丸。

### 4.5 演练

演练按位置一至位置五顺序处理。对每个位置：

1. 在对应位置识别「挑战」或「失败」。
2. 识别到失败时记录失败并转往下一个位置；既非挑战也非失败时视为已胜利。
3. 识别到挑战时进入对手情报页。
4. 关闭避战强敌时直接点击「进入演练」；开启时先执行危险度判断。
5. 不是强敌后，点击 `[1146, 581, 109, 92]` 的「进入演练」区域，并在该区域冻结 500ms。
6. 部队选择步骤会按用户配置的位置点击两次：首次点击后等待 500ms，第二次点击使用同一份选项覆盖的位置。
7. 选择阵形后进入战斗。战斗枢纽识别经验、战斗结果、演练对手情报与演练对手选择页面。
8. 回到对手选择页时，复查当前位置：可挑战则再次挑战；失败则记录失败；两者均未命中则记录一次胜利。

危险度规则：六把刀剑分别检查极化标志，极化刀剑每把危险度加一；OCR 刀名区域出现「丙子」时危险度加一。危险度达到六时点击离开，输出「日课 演练 位置 N 判定为强敌，跳过」。

累计三次胜利或处理完五个位置后结束演练并返回本丸。

### 4.6 领取奖励

1. 从本丸进入任务入口与任务页。
2. OCR「任务列表」后进入奖励领取枢纽。
3. 检测奖励颜色，命中时点击领取并输出「日课 领取奖励 完成」。
4. 未检测到可领取奖励时输出「日课 领取奖励 未检测到可领取奖励」。
5. 循环识别并点击右上角关闭按钮，直到不再识别到关闭按钮后结束日课。

## 五、返回本丸设计

登录奖励、暖心礼包、合成、锻刀、演练、检非违使各自拥有同构的返回本丸枢纽：

1. 先进行左上角亮度检测。
2. 已在本丸时通过本丸模板确认，并前往下一个 Gate。
3. 否则识别右上角目录并点击。
4. OCR「本丸」并点击。
5. 回流枢纽，直到检测到本丸。

点击操作均在对应识别区域冻结 200ms。返回本丸枢纽保留独立的兜底等待流程，避免影响业务主枢纽的识别顺序。

## 六、同步后勤

启用「同步后勤」后，日课在确认回到本丸时先处理一次后勤，再继续执行各日课项目。该选项与出阵任务的同步后勤共用「后勤」任务里保存的部队、修刀、内番与刷新间隔配置，项目在设置页中位于第一位。

### 6.1 接入位置

`DT_DetectWhereAmI` 的本丸确认链为 `DT_CheckHomeBrightness → DT_IsHome → DT_CheckHomeBrightness2 → DT_IsHome2 → DT_PrepareHub`。启用同步后勤时覆盖 `DT_IsHome.next`：

```json
"DT_IsHome": {"next": ["Expedition"]}
```

即本丸确认后直接进入共用后勤流程，后勤结束回到 `DT_PrepareHub` 继续日课，与花牌、陆联、地下城等任务「回本丸即同步后勤」的接线方式一致。

### 6.2 后勤收尾与回落

| 覆盖 node | 值 | 说明 |
|---|---|---|
| `E_AllTeamsBusy` | Click `[230,12,71,19]`，`repeat: 2`、`repeat_delay: 500`，`next: ["DT_PrepareHub"]` | 点掉队伍状态面板后直接回日课 |
| `E_ClickBackToHome` | Click `[1037,169,110,44]`，`next: ["DT_WaitRefresh"]`，`on_error: ["DT_DetectWhereAmI"]` | 后勤途中跑偏时先回本丸再回后勤检查链 |
| `E_SelectMap1~5` | `ExpeditionMapSelectAction`，`team` 1~5 | 与其它任务相同 |
| `E_ClickSmallMap1~5` | `enabled: false` | 同步场景不点小地图 |
| `E_VerifyScreen1~5` | `on_error: ["E_CheckTeamStatus"]` | 验证失败回落队伍状态面板 |

日课不启动远征倒计时，也不做队伍面板 OCR 扫描，因此不覆盖 `E_TimerStart`，`E_AllTeamsBusy` 之后直接离开后勤流程。`E_AllTeamsBusy` 的 `action` 必须在任务层写死为关闭面板的点击：开启「远征智能调度」时，全局覆盖会把该 node 的动作改成 `DoNothing`，不写死就会让队伍状态面板留在画面上，后续日课项目点不到入口。

### 6.3 新增 node

`DT_WaitRefresh` 承接 `E_ClickBackToHome`：本丸模板 `[8,1,71,107]`、`post_delay 1000`、`next: ["E_CheckTeamStatus"]`、`on_error: ["DT_DetectWhereAmI"]`，与 `S_WaitRefresh`、`U_WaitRefresh` 同构。

### 6.4 使用注意

- 演练使用的部队必须在「本丸后勤」任务里设为休息，否则会被先派遣远征，导致演练选队失败。
- 后勤的内番与远征指派可能让部分刀剑在日课刀解界面不可选，此时日课按既有兜底跳过锻刀并输出「可刀解刀剑不足」，不会卡死。
- 「本丸后勤」任务不在任务列表中时，同步到的队伍与修刀配置回落到默认值，这一点与出阵任务的同步后勤一致。

## 七、测试边界与后续事项

- 一键日课目前处于测试阶段，必须有人看管；尤其是演练、锻刀、刀解与画面恢复路径。
- 锻刀、刀解与合成依赖全局「刀解/合成许可名单」，执行前需确认名单内容符合预期。
- 日课不内置「开始前启用预设部队」：需要在日课前编成部队时，启用任务列表中的「自定编队」任务即可，它默认排在日课之前。自定编队任务支持勾选多个预设并按列表顺序依次编成。
- 检非违使功能暂未向用户开放，需要在识别稳定、出阵地图及战斗恢复逻辑完成实测后再恢复注册。
- 每次调整 OCR、模板阈值、坐标或冻结时间后，应通过开发区日志验证实际命中链路，避免通过无条件点击掩盖识别问题。
- 日课的各业务枢纽与各阶段 Gate 已在 pipeline 中写死 `timeout: 120000`，不再依赖「卡死重启」开关；该开关现在只切换 `on_error` 指向的恢复 node。
- 同步后勤待实机验证：日课启动首个命中的 DT node 为 `DT_IsHome`（不再是 `DT_DetectClickMenu`）、后勤结束后回到 `DT_PrepareHub` 并继续日课、以及演练部队与后勤配置冲突时的表现。
