# v1.0.1-beta.5

## 【 v1.0.1-beta.5 】 (2026-11-28)

### 新增

* 支持直接编辑单段已保存工作记录的资源收获，可添加、删除和修正资源名称、数量与获取次数。
* 单段已保存记录的任务概况显示具体开始和结束时间。
* 资源收获标题显示获取次数汇总。

### 修复

* 修复百鬼迎击与百鬼强化未应用疲劳处理阈值设置的问题。
* 修复习合达到满级后仍重复选择材料的问题。
* 修复加速符库存未从背包响应中读取的问题。
* 修复刀剑掉落播报没有按当前实例应用开关与关注名单的问题。
* 暂停江户潜入中其他活动页面的检测挂载，避免误判并结束任务。

### 依赖更新

（无）

### 优化

* 调整内番记录表格的滚动布局，为滚动条预留空间。

**版本变更**：v1.0.1-beta.4 → v1.0.1-beta.5
