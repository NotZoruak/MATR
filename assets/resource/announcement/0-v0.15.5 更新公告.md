# v0.15.5

## 【 v0.15.5 】 (2026-11-05)

### 新增

* 仓库趋势图支持缩放时间范围、独立滚动和显示平均变化速率；其他资源栏可收起，趋势图会自动扩展。
* 掉落记录显示刀剑掉落总数，自定编队预设支持跨实例复制和粘贴。
* 增加疲劳恢复页面的通用识别与关闭处理。
* 性能设置新增“强制开启”GPU 推理选项，可显式请求 DirectML GPU 0。

### 修复

* 修复出阵、远征、习合、信箱筛选、阵容配置等流程中可能停滞、误判或无法继续的问题。
* 延长无点击卡死重启的判定时间，减少战斗和加载期间的误判。
* 修正计划任务工作记录告警、冷材奖励名称及刀剑掉落数量单位。

### 优化

* 工作记录卡片高度随记录数量调整，刀剑掉落总数使用“×数量”格式。
* 模板匹配阈值不低于 0.98 的节点调整为 0.97，提升对画面差异的容忍度。
* 恢复四线程 CPU OCR 并关闭空闲自旋，默认识别间隔由 1000 毫秒恢复为 500 毫秒。
* 导出日志前清理过期及超量日志，控制导出内容规模。
* 补充活动任务购票说明。

**版本变更**：v0.15.4 → v0.15.5
