# v0.15.3

## 【 v0.15.3 】 (2026-10-25)

### 新增

* 江户潜入新增「自动行军」策略，并设为默认选项，使用游戏内委托功能；原有四种策略仍可选择。
* 数据查询中的极化经验表与经验计算支持至 199 级。
* 开启地下城「更多点击」后，不再记录刀剑掉落信息。
* 新增江户潜入购买门票流程对于新 UI 的适配。

### 修复

* 修正「继续下一轮」的按钮状态判断。
* 提高一键日课中演练战斗结算的识别稳定性。
* 修正本丸后勤中的内番待机状态识别。
* 调整远征归还经验结算的点击区域，减少误触其他界面区域的情况。
* 修正白山修刀过程中界面尚未切换就继续操作的问题。
* 修正切换设置分类时未自动返回上级设置页的问题。

### 优化

* 优化对地下城活动教程的识别。
* 优化地下城出阵确认、小判箱掉落识别与流程衔接。
* 地下城触发重伤或刀装破坏保护后，撤退回本丸并结束当前任务。
* 调整地下城重伤与刀装保护撤退提示，便于在任务日志中查看。

**版本变更**：v0.15.2 → v0.15.3
