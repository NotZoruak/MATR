# v0.13.0-beta.6

## 【 v0.13.0-beta.6 】 (2026-09-07)

由于此前版本存在资源路径错误问题，若通过程序内自动更新后显示**资源加载失败**，请重新前往 [Releases 页面](https://github.com/NotZoruak/MATR/releases) 下载最新版本，解压后覆盖程序根目录中的文件。

### 新增

* 刀帐工具新增筛选功能，可按刀剑拥有状态以及中伤、真剑、内番、轻装立绘拥有状态筛选显示结果。
* 本丸仓库的核心资源变化图表新增 24 小时、7 天和 30 天时间范围筛选，支持 X 轴时间刻度以及悬停查看当前值和资源变动量。
* 一键日课“领取奖励”支持分别选择日常、月常、主线与活动任务奖励。
* 一键日课新增“领取邮件”项目，可按资源、刀装、货币、便利道具、其他物品与景趣类别领取邮件。
* 支持自动行军状态双向切换。

### 修复

* 修复刷花任务移除队员后无条件点击换队长的问题。
* 修复异步任务队列提前进入停止流程的问题，同时修复工作记录保存与日志导出反馈入口异常。
* 修复开启卡死重启后，一键日课部分 hub 超时未触发游戏重启的问题。
* 修复部分模拟器缺少 `monkey` 命令或无法解析包名启动 Intent，导致游戏重启失败的问题。
* 修复一键日课演练胜利判定偶发无法完成的问题。
* 放宽合战场“异去”模式的补充门票识别范围，修复部分门票无法识别的问题。
* 修复刀剑掉落播报无法识别初掉落的问题，改用纯色匹配识别掉落动画。
* 修复一键日课弹窗处理顺序，弹窗优先于业务操作，避免弹窗干扰导致操作错位。
* 一键日课演练胜利判定增加 OCR 确认，识别异常时回到对应对手流程重试，不再误入结束。
* 修复自定编队选刀偶发误选近似名刀剑的问题。

### 优化

* 优化卡死恢复日志，区分模拟器重启失败与游戏启动失败。
* 优化任务队列间的回本丸处理。
* 优化了任务列表的 UI 设计。
* 优化了修刀资源识别范围。
* 日课卡死重启后会回到触发恢复的原流程继续执行，避免从不确定位置恢复。
* 优化疲劳和内番记录显示：首位疲劳值识别失败时继续出阵，内番派遣与内番服结果在工作记录中合并显示。
* 优化 GUI 日志文案，缩短远征派遣和倒计时日志内容。

### 依赖更新

* 升级 MFAAvalonia 至 v2.16.1，并适配新的任务设置与发布结构。
