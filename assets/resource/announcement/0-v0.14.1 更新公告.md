# v0.14.1

## 【 v0.14.1 】 (2026-09-17)

### 新增

* 日课设置页在复选项下方显示「今日已完成」，运行中写入记录后自动刷新

* 新增刀剑极化归来自动截图

### 修复

* 修复「一键日课」选择「锻刀 → 锻刀公式 → 限锻优先」时，非限锻期没有回落出口、任务停在锻刀资源投入页失败的问题，现在判定不到限锻会立即改用 ALL 50 继续锻刀

* 修复遇到「修行申请」弹窗时识别不到、空转到卡死重启的问题

* 修复「全局」设置中的开关与输入项重启后回到旧值的问题

* 修复多开时一键日课的完成记录互相串用的问题，完成记录与本次运行的跳过状态改为按实例分别保存

* 修复习合搓糖在习合完成返回选刀画面时因白屏过渡中断的问题

* 修复习合搓糖在「全部解除」后重新选择素材时多选素材导致中断的问题

* 修复极化归来对话被误判为刀剑掉落的问题

* 修复部分情况下刀剑掉落记录与播报的刀名、刀种识别不准确的问题

* 修复内番服未识别到立绘时，工作记录里的后勤明细被整条丢弃的问题

* 修复启动后偶尔忘记上次选择的模拟器、需要重新选择设备的问题

* 修复自定编队进入「刀剑男士选择」页后卡住不动的问题

### 优化

* 一键日课任务重构，各项目流程与完成状态展示重写

* 优化秘宝之里一圈结束判定

* 工作记录的任务概况不再显示行军次数

* 修刀、刀解、合成与仓库扫描四处的列表翻页统一为 L 形上滑手势

### 依赖更新

* MaaFramework 原生运行时升级至 5.13.1：跟进 MuMu 模拟器的 display id 缓存修复，以及 Windows 平台的截图与输入链路修复
