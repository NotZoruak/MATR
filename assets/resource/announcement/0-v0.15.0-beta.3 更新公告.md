# v0.15.0-beta.3

## 【 v0.15.0-beta.3 】 (2026-10-06)

### 修复

* 修复仅使用部队记录时仍受预设成员配置影响的问题，并修正保存记录后的流程跳转。
* 修复加速符修刀流程可能因为伤势最重的成员无法选中而卡死的问题。
* 修复远征编队因刀名 OCR 漏字误判成员并解散已有队伍的问题。
* 修复海陆联队识别到完成或撤退提示后仍重复点击的问题。
* 修复自定编队遇到刀剑没有对应刀装槽位时重复记录特殊情况的问题。
* 修复外部通知未汇总任务提前结束原因的问题。

### 优化

* 优化无加速符时的修刀确认流程，并调整地下城重伤修刀后的任务结束处理。
* 后勤智能调度在开启内番时会将内番剩余时间纳入计时；远征与内番均关闭时按用户设置的刷新间隔检查。
* 优化内番耕作加成满值跳过选项，改为开启后直接选择生存满、侦察满、任一满或全满条件。

#### **版本变更**：v0.15.0-beta.2 → v0.15.0-beta.3
