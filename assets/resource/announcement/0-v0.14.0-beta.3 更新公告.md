# v0.14.0-beta.3

## 【 v0.14.0-beta.3 】 (2026-09-11)

### 新增

* 一键日课的「锻刀公式」新增「限锻公式」与「限锻优先」两档：限锻公式在检测到当期限锻时自动勾选并锻刀，没有限锻活动时跳过当天锻刀；限锻优先在没有限锻活动时改用 ALL 50

### 修复

* 修复了一键日课收取锻刀完成的刀剑后，获得的刀剑没有计入工作记录「任务收获」的问题
* 修复了自定编队装备刀装时可能停留在更换装备页面反复识别、无法继续的问题
* 修复了开启「卡死重启」后，一键日课演练战斗进行中被误判为卡死并重启游戏的问题
* 修复了远征任务可能卡死在远征状况面板的问题

### 优化

* 优化了编队预设的选择方式：自定编队支持勾选多个预设，按设置页从上到下的顺序依次编成
* 精简了一键日课：不再内置「开始前启用预设部队」，需要先编队时把自定编队任务排在日课之前即可
* 优化了一键日课的刀解锻刀流程：进入锻刀后先检查刀位再执行刀解，日课刀解与腾位刀解合并为一次完成，不会按上一次的刀位缺口多解刀剑
