# v0.14.0-beta.4

## 【 v0.14.0-beta.4 】 (2026-09-12)

### 新增

* 新增「Windows 定时唤醒」：程序和模拟器都没有运行时，由 Windows 计划任务在设定时间自动启动指定实例并执行任务；程序已经在运行时按现有实例执行，开启「强制定时启动」时会先停止当前任务再开始。关闭程序不会取消定时，只有关闭定时开关或删除该定时才会取消

**提示**：定时任务保存在 Windows 任务计划程序里。整体移动 MATR 文件夹时，新位置首次启动会自动清理旧位置留下的任务；如果要**删除** MATR 文件夹，请先关闭定时设置里的启动开关，否则会留下需要手动清理的残留任务。

* 一键日课新增「同步后勤」选项：使用「本丸后勤」任务中的设置，在日课开始前先处理一次远征派遣、修刀与内番，再执行各日课项目；请在「本丸后勤」任务中把演练要用的部队设为休息

* 刀帐筛选改为单行表头：已拥有、中伤、真剑、内番、轻装五列的下拉收起时显示列名，选中「已拥有」或「未拥有」时列名与边框高亮；展开后「全部」「已拥有」「未拥有」后面显示对应刀剑数量，勾选、清空、撤销或自动识别后数量立即刷新

* 刀帐新增刀种筛选：刀种列的下拉可以同时勾选多个刀种（短刀、胁差、打刀、太刀、大太刀、枪、薙刀、剑，各带全量数量），只勾选其中几种时列名高亮，全部勾选或都不勾等同于不筛选

### 修复

* 修复一键日课在演练出阵等画面停留较久时输出「检测到游戏疑似卡死」并重启游戏的问题：日课的画面检测枢纽与各阶段入口统一按 120 秒等待，且不再依赖「卡死重启」开关

### 优化

* 优化了「修行申请」对话与弹窗的识别方式

* 优化了一键日课的合成目标刀选择逻辑

* 优化了一键日课的登录奖励领取流程
