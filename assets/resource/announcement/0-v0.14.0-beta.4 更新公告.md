# v0.14.0-beta.4

## 【 v0.14.0-beta.4 】 (2026-09-11)

### 新增

* 新增「Windows 定时唤醒」：程序和模拟器都没有运行时，由 Windows 计划任务在设定时间自动启动指定实例并执行任务；程序已经在运行时按现有实例执行，开启「强制定时启动」时会先停止当前任务再开始
* 定时设置新增计划任务同步状态提示，可以直接看到同步结果和失败原因
* 关闭程序不会取消定时，只有关闭定时开关或删除该定时才会取消
* 一键日课新增「同步后勤」选项：使用「本丸后勤」任务中的设置，在日课开始前先处理一次远征派遣、修刀与内番，再执行各日课项目；请在「本丸后勤」任务中把演练要用的部队设为休息

### 修复

* 修复一键日课在演练出阵等画面停留较久时输出「检测到游戏疑似卡死」并重启游戏的问题：日课的画面检测枢纽与各阶段入口统一按 120 秒等待，且不再依赖「卡死重启」开关

### 优化

* 优化了「修行申请」对话与弹窗的识别方式
* 调整任务列表顺序：「自定编队」移到「一键日课」之前
