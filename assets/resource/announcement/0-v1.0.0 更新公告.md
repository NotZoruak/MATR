# v1.0.0

## 【 v1.0.0 】 (2026-11-26)

### 新增

* 新增百鬼迎击、百鬼强化活动任务。
* 两项活动均支持出阵成功后重启游戏进行速刷。
* 战术强化支持固定选择九宫格位置。
* 重伤处理新增白山修刀选项，并支持选择普/极白山修刀。
* 刀解清仓支持仅刀解全局设置中许可名单中刀剑。

### 修复

* 修复日志区域重新获得焦点时滚动位置跳回的问题，并恢复返回任务页后的日志底部跟随。
* 修复独立后勤检查与等待流程，以及关闭后勤面板的过渡期间反复返回本丸的问题。
* 修复出阵撤退确认分支、空邮箱刀解循环、自定编队弹窗处理和习合空列表误判。
* 修复补充异去提灯时可能卡住的问题，以及异去门票确认后的流程识别与异常返回问题。
* 修复仓库页面资源卡片在深色主题下的显示问题，卡片背景和边框随界面主题切换。
* 修复异去出阵成功后未正常计入出阵次数的问题。
* 修复刀解清仓、编队记录确认及活动任务流程中的识别与返回问题。

### 优化

* 将工具与资料查询整合为工具。
* 剪影识别统一使用客户端剪影图库。
* 「记录中刀装不足时使用自动装备刀装」改为滑动开关。
* 优化编队、仓库、刀帐、收获记录和工具箱等页面的布局与筛选体验。
* 优化远征与刷花流程、任务状态报告及外部通知内容。
* 补充习合搓糖操作提示。
* 优化远征与战斗结算页面的点击位置。
* 优化全局包名输入框宽度。
