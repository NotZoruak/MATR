# v0.14.3

## 【 v0.14.3 】 (2026-09-25)

### 新增

* 新增刷收获物任务，支持自动选择活动地图并收取收获物。
* 海陆联队任务增加对海联的支持。
* 仓库新增核心资源对比图，可直观查看资源数量变化。
* 自定编队支持为每个位置配置宝物、三种刀装和马匹，并在编队时自动装备
* 刀装选项新增乐器兵和水炮兵，并继续兼容旧版连续刀装配置。
* 补充刀装功能支持在记录不足时自动补充刀装。

### 修复

* 修复习合翻页后刀剑列表识别和素材识别不稳定的问题。
* 修复限锻计算器遇到卡死画面时无法继续识别的问题。
* 修复历史 ADB 地址无法恢复直连的问题

### 优化

* 完善海陆联队活动流程及队伍切换处理。
* 优化刀装撤退日志，仅将相关记录写入日志文件并保留特殊标记。
* 优化自定编队设置界面，在窄窗口和滚动状态下保持编号、输入框、下拉框与滚动条对齐。
* 统一自定编队中刀剑、宝物、刀装和马匹选项框的尺寸、间距与边框显示。

### 变更

* 移除问题反馈相关的问卷链接，统一改为使用 GitHub Issue。

#### **版本变更**：v0.14.2 → v0.14.3
