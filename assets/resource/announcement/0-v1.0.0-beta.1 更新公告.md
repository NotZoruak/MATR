# v1.0.0-beta.1

## 【 v1.0.0-beta.1 】 (2026-11-14)

### 新增

* 重伤处理新增独立的「白山修刀」选项，使用前请阅读选项中的御守、喜爱标记及速度要求等注意事项。

### 修复

* 修复日志区域重新获得焦点时滚动位置跳回的问题，并恢复返回任务页后的日志底部跟随。
* 修复独立后勤检查与等待流程，以及关闭后勤面板的过渡期间反复返回本丸的问题。

### 优化

* 将工具与资料查询整合为工具箱。
* 剪影识别统一使用客户端剪影图库。
* 「记录中刀装不足时使用自动装备刀装」改为滑动开关。
