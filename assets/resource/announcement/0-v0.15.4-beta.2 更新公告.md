# v0.15.4-beta.2

## 【 v0.15.4-beta.2 】 (2026-10-28)

### 修复

* 修复自动刷取内番服时可能卡在饲马选择页面的问题，按入手顺序升序选刀，并检查目标是否上锁且可选；补位只检查可选状态。
* 将各任务刀名 OCR 的最低得分要求降至 0.7，修复部分生僻字刀名出现在列表中却被漏选的问题。

### 依赖更新

* MaaFramework 原生运行库更新至 5.14.3。

### 优化

* 降低 Windows OCR 推理线程数量，并适度降低等待画面变化时的识别频率，减少任务运行时的 CPU 开销。
* 优化地下城刀装破坏后的任务结束与返回本丸流程，避免后勤计时结束时因无效跳转导致任务失败。

**版本变更**：v0.15.4-beta.1 → v0.15.4-beta.2
