# v0.14.2

## 【 v0.14.2 】 (2026-09-21)

### 新增

* 限锻资源计算器新增「读取仓库数据」按钮，可从已保存的仓库数据填入资源、御札、委托符和加速符。

* 「一键日课」支持按任务分别设置更新数据触发间隔，并显示上次更新时间。

* 「远征智能调度」支持自动使用堆肥。

### 修复

* 修复活动流程中部分页面识别失败、重复点击或停在中间页面的问题。

* 修复「更新数据」在刀帐扫描、队伍状态面板和远征结果页面可能卡住的问题。

* 修复「秘宝之里」选择难度后可能误识别 PT 已达成目标，导致提前结束任务的问题。

* 修复后勤修刀时首位可修刀剑识别不准确的问题。

* 修复部分任务的疲劳检测和队伍切换链路异常问题。

### 优化

* 优化「刀解/合成许可名单」与「刀剑掉落播报」的刀剑选择，支持同时按刀剑名称和刀种搜索，并支持重复点击切换选择状态。

* 优化刀剑掉落播报：命中播报名单时，同时在系统通知和 GUI 日志中显示播报内容。

* 优化「远征智能调度」的任务说明。

* 优化多个任务的弹窗、加载和异常页面处理。

#### **版本变更**：v0.14.1 → v0.14.2
