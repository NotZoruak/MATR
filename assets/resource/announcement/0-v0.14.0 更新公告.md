# v0.14.0

## 【 v0.14.0 】 (2026-09-13)

### 新增

* 新增「Windows 定时唤醒」：程序没有运行时，由 Windows 计划任务在设定时间自动启动指定实例并执行任务；程序已经在运行时按现有实例执行，开启「强制定时启动」时会先停止当前任务再开始。关闭程序不会取消定时，只有关闭定时开关或删除该定时才会取消

**提示**：定时任务保存在 Windows 任务计划程序里。整体移动 MATR 文件夹时，新位置首次启动会自动清理旧位置留下的任务；如果要**删除** MATR 文件夹，请先关闭定时设置里的启动开关，否则会留下需要手动清理的残留任务。

* 新增「秘宝之里」（花牌）活动任务：固定开启自动行军，支持达成报酬、门票确认与门票不足处理；可开启「达到目标PT后跳过任务」，设置目标总 PT 与日期计划后按日线性推进，达标即跳过剩余轮数

* 后勤「内番」新增「联动本丸刀帐」：识别到内番服立绘后自动同步保存至本丸刀帐，无需先在刀帐页手动保存；其下新增「自动刷取内番服」，自动安排已拥有但缺少内番服立绘的刀剑男士

* 常驻作战「过去」新增避战检非：遭遇检非违使时自动重启游戏，并把这次异常记录到工作记录

* 一键日课新增「同步后勤」选项：使用「本丸后勤」任务中的设置，在日课开始前先处理一次远征派遣、修刀与内番；请在「本丸后勤」任务中把演练要用的部队设为休息

* 一键日课的「锻刀公式」新增「限锻公式」与「限锻优先」两档：限锻公式在检测到当期限锻时自动勾选并锻刀，没有限锻活动时跳过当天锻刀；限锻优先在没有限锻活动时改用 ALL 50

* 刀帐筛选扩展为单行表头：已拥有、中伤、真剑、内番、轻装五列的下拉收起时显示列名，展开后显示对应刀剑数量；新增刀种筛选，可同时勾选多个刀种，每项带全量数量

* 自定编队支持勾选多个预设，按设置页从上到下的顺序依次编成

### 修复

* 修复一键日课在游戏重启后无法处理登录页，可能连续触发重启的问题

* 修复开启「卡死重启」后，一键日课在演练战斗、出阵等待等画面停留较久时被误判为卡死并重启游戏的问题：日课的检测枢纽与阶段入口统一按 120 秒等待，且不再依赖「卡死重启」开关

* 修复自定编队在识别到生僻字或形近字刀名时无法选择刀剑的问题：「祢祢切丸」「静形薙刀」「巴形薙刀」等刀名现在可以正确匹配

* 修复自定编队装备刀装时停留在更换装备页面反复识别、无法继续的问题，刀刃选择前先检查队伍空位

* 修复一键日课收取锻刀完成的刀剑后，获得的刀剑没有计入工作记录「任务收获」的问题

* 修复远征任务可能卡死在远征状况面板的问题：进入远征入口后先等待画面稳定再校验

* 修复地下城、联队战、战术强化与秘宝之里返回时部队状态面板残留、流程无法继续的问题

* 修复日志面板偶尔把「开始任务」与「任务完成」顺序颠倒的问题

* 修复一次刀剑掉落被重复记录、重复播报的问题

* 修复多实例下同步后勤读取到其它实例的部队设置，导致休息的部队仍被派遣、流程反复回到本丸无法继续任务的问题：现在选图与派遣按执行任务那个实例的配置判断，休息的部队会在进入选图前跳过

* 修复多实例下远征派遣记录、GUI 日志与工作记录写入其它实例的问题

* 修复唤醒本丸点击后偶发重复点击的问题，点击之间增加重复与间隔

* 修复合战场疲劳值为 0 时被误判为识别失败的问题：低疲劳的刀剑现在可以正常进入刷花

* 修复设置「关于我们」中的「使用教程」按钮只弹提示、无法播放教程的问题，同时修正教学引导的高亮范围

* 修复资源点资源获取数量识别不稳定的问题

* 修复江户潜入活动页导航失败后无法回落的问题

### 优化

* 联队战、江户潜入、战术强化、合战场异去与秘宝之里的门票设置由「不买门票」改为「购买门票」：勾选后令牌不足时自动购买，不勾选时结束当前任务

* 常驻作战与江户潜入在指定的重伤、刀装破坏或通行令牌不足等情形下，可提前结束当前任务的剩余重复次数并继续后续任务；结束原因会显示在工作记录的特殊情况中

* 合战场「过去」与「异去」的重复次数统一为任务级设置，旧配置会自动迁移，不再需要单独填写下级选项

* 常驻作战优化疲劳处理与刷花打点，刷花次数的统计更准确

* 一键日课精简：不再内置「开始前启用预设部队」，需要先编队时把自定编队任务排在日课之前即可

* 一键日课的锻刀与刀解流程调整为先检查刀位再执行刀解，日课刀解与腾位刀解合并为一次完成，不会再按上一次的刀位缺口多解刀剑；合成目标刀的选择与登录奖励的领取流程同步优化

* 优化「修行申请」对话与弹窗的识别方式

* 任务列表默认顺序调整为「唤醒本丸 → 更新数据 → 自定编队 → 一键日课 → 出阵类任务」，并统一带同步后勤任务的说明文案

* 工作记录页面卡片支持收起与展开，跨天记录与后勤明细补上月日，时间与耗时显示更清晰

* 主窗口默认尺寸调整为 900×675；设置页顶部导航字号加大，并支持按住导航文字或同高度留白横向拖动

* 任务设置中的内联子选项补上说明文字显示，不再只在齿轮子页面里能看到选项说明

* 兼容 QMsg v3 推送接口
