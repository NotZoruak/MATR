# v0.14.0-beta.1

## 【 v0.14.0-beta.1 】 (2026-09-10)

### 新增

* 常驻作战——过去 新增避战检非功能
* 后勤内番新增“联动本丸刀帐”，识别到内番服立绘后可自动同步保存至本丸刀帐
* 联动本丸刀帐新增“自动刷取内番服”，自动安排已拥有但缺少内番服立绘的刀剑男士
* 新增秘宝之里（花牌）活动任务
* 秘宝之里支持“达到目标PT后跳过任务”：可设定目标总 PT，并按日期计划每日线性推进，达标后自动跳过剩余轮数

### 修复

* 修复资源点资源获取数量识别不稳定的问题
* 修复一键日课在游戏重启后无法处理登录页，可能连续触发重启的问题
* 修复自定编队在识别到生僻字时无法选择刀剑的问题：「祢祢切丸」「静形薙刀」「巴形薙刀」等生僻字刀名现在可以正确匹配

### 优化

* 兼容 QMsg v3 推送接口
* 常驻作战与江户潜入在指定的重伤、刀装或通行令牌不足情形下，可提前结束当前任务的剩余重复次数并继续后续任务；结束原因会显示在工作记录的特殊情况中
* 联队战、江户潜入、战术强化与合战场异去的门票设置由“不买门票”改为“购买门票”：勾选后令牌不足时自动购买，不勾选时结束任务
