# v0.14.2-beta.3

## 【 v0.14.2-beta.3 】 (2026-09-21)

### 新增

* 限锻资源计算器新增「读取仓库数据」按钮，可从已保存的仓库数据填入四项资源、御札、委托符和加速符。

### 修复

* 修复了「秘宝之里」选择难度后可能误识别PT已达成目标，导致提前结束任务的问题

### 优化

* 优化「刀解/合成许可名单」与「刀剑掉落播报」的刀剑选择，支持同时按刀剑名称和刀种搜索。

* 候选刀剑支持重复点击切换选择状态。

* 优化限锻资源计算器的屏幕识别提示。

* 优化「远征智能调度」的任务说明。

* 优化刀剑掉落播报：命中播报名单时，同时在系统通知和 GUI 日志中显示播报内容，且不影响工作记录中的刀剑掉落统计。

#### **版本变更**：v0.14.2-beta.2 → v0.14.2-beta.3
