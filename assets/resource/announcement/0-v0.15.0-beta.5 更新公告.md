# v0.15.0-beta.5

## 【 v0.15.0-beta.5 】 (2026-10-07)

### 新增

* 新增“平滑定时切换”：强制定时启动触发时，正在执行的普通任务完成当前一圈后停止任务队列，再启动定时任务。

### 修复

* 修复切换定时操作类型后结束选项未及时刷新的问题。
* 修复返回本丸时无法处理活动结算界面的问题。
* 修复合战场和刷收获物任务部分失败路径未回到任务主枢纽的问题。
* 修复外部任务通知未汇总失败任务及原因的问题。

### 优化

* 统一任务选项说明。
