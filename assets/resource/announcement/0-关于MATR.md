# 关于 MATR

MATR 是基于 **MaaFramework** 开发的《刀剑乱舞》自动化助手，通过识别游戏画面和模拟操作，帮助审神者完成重复性的日常任务。目前仅推荐模拟器在 **1280*720，240 DPI 分辨率**下使用。

本项目**免费开源**，仅供学习交流使用。MATR 仅通过游戏界面进行交互，不会修改游戏文件或读写游戏内存。

## 使用约定

请勿在游戏官方讨论群组、官方账号动态及相关评论区宣传或讨论 MATR，也请勿携带官方活动标签进行传播。

请尊重其他玩家的游玩方式，不以使用自动化工具炫耀或嘲讽手动操作的玩家。和谐交流，低调使用。

使用本应用可能违反游戏条款。请在了解风险后自行决定是否使用，**由此产生的后果（包括账号封禁、数据丢失等）由使用者自行承担**。

## 一起完善 MATR

目前项目的长期维护主要由一人承担，精力和时间有限，新功能开发与 bug 修复可能需要较长时间。感谢大家的耐心等待，也希望大家多一些理解与包容。

MATR 仍在持续完善中，欢迎分享使用体验、反馈问题、提出建议或贡献代码。

特别感谢 [@Severus-Yang0](https://github.com/Severus-Yang0) 为 MATR 提供 macOS 支持，让使用 Mac 的审神者也能使用 MATR。

感谢每一位愿意使用、测试和帮助改进 MATR 的审神者，也感谢 MaaFramework 与 MFAAvalonia 为本项目提供的支持。
